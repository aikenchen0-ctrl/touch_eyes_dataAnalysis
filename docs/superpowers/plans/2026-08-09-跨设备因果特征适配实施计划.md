# 跨设备因果特征适配实施计划

> **给执行代理：** 使用 `superpowers:executing-plans` 按任务逐项执行。每项任务先写行为测试，再实现最小代码；原始 schema v6 JSON 只读，禁止直接改写或删除。

**目标：** 为 schema v6 建立跨设备因果特征契约，先把平台单位、坐标系和字段缺失适配到共同语义，再按真实硬件时间重采样到固定 `-15ms...+25ms` 网格，确保 Python 训练端和 Android 端使用完全相同的输入。

**架构：** 保留现有 v1 原始帧契约和旧模型。新增 v2 适配器负责平台元数据校验、IMU 轴/单位变换、触摸单位归一化、字段可用性掩码和时间网格重采样；Python 与 Java 各有同一份 fixture 和契约测试。v2 模型通过 scaler 中的 `featureContract` 显式分派，不依赖通道数猜测。

**技术栈：** Python 标准库、Android Java、`org.json`、JUnit、现有 PyTorch 训练脚本、现有 schema v6 JSON。

## 任务 2：实现 Python 平台单位和坐标适配器

**文件：**

- 创建：`android/analysis/cross_device_causal_features.py`
- 修改：`android/analysis/causal_press_features.py`
- 修改：`android/analysis/tests/test_cross_device_causal_features.py`

- [ ] 定义 `PlatformSensorContract`，至少包含 `platform`、`sensorSource`、`sensorUnit`、`sensorAxisFrame`、`displayRotation` 和 `transformVersion`。
- [ ] 定义 canonical 设备坐标系：`canonical.x = device_right`、`canonical.y = device_up`、`canonical.z = device_outward`；所有平台都转换到该坐标系。
- [ ] 对线性加速度和 iOS `userAcceleration` 统一到 `m/s^2`。
- [ ] Android 普通加速度计若包含重力，必须要求同一时间轴上的重力值并执行 `linear = acceleration - gravity`；无法完成时拒绝 v2 样本，不能把含重力数据伪装成线性加速度。
- [ ] 对陀螺仪统一到 `rad/s`，执行同一轴变换和符号变换。
- [ ] 对 `sensorAxisFrame`、单位、平台或变换版本缺失时返回明确错误码，不静默使用默认轴。
- [ ] 轴变换在时间重采样之前执行，保证不同采样率的同一物理运动落入同一 canonical 空间。

## 任务 3：实现触摸单位、屏幕尺寸和缺失掩码适配

**文件：**

- 修改：`android/analysis/cross_device_causal_features.py`
- 修改：`android/analysis/causal_press_features.py`
- 修改：`android/aispect-core/src/main/java/com/zhifaios/eyes/aispect/AispectTouchFrame.java`
- 修改：`android/aispect-core/src/main/java/com/zhifaios/eyes/aispect/AispectDataLogger.java`
- 修改：`android/aispect-core/src/test/java/com/zhifaios/eyes/aispect/RawFrameSchemaTest.java`

- [ ] 在 `touchFrames[]` JSON 中保存 `viewWidthPx` 和 `viewHeightPx`，与当前内存中的 `width/height` 完全一致。
- [ ] 保存 `touchUnit`、`touchTransformVersion` 和 `axisAvailability`，避免将 Android 像素、iOS points 和系统归一化值混为同一单位。
- [ ] 生成共同触摸特征：`x_norm`、`y_norm`、`size`、`major_norm`、`minor_norm`、`log_axis_ratio`。
- [ ] `major_norm` 和 `minor_norm` 默认使用屏幕对角线归一化；屏幕尺寸缺失时拒绝需要半径的契约，不使用假定尺寸。
- [ ] 为压力、面积、长轴、短轴、方向、指针数量分别生成可用性掩码；缺失值保留为数值占位，但掩码必须区分“缺失”和“真实零值”。
- [ ] 不把缺失半径填成默认真实半径；如果契约包含接触形状，模型必须明确接收掩码或走无形状 fallback 契约。
- [ ] `touchFrames[].contactPatch` 和根级汇总不参与 v2 特征构建。

## 任务 4：实现固定物理时间网格重采样

**文件：**

- 修改：`android/analysis/cross_device_causal_features.py`
- 修改：`android/analysis/causal_press_features.py`
- 修改：`android/analysis/tests/test_cross_device_causal_features.py`

- [ ] 新增契约 `causal_time_grid_imu11_v2` 和 `causal_time_grid_imu11_touch9_v2`。
- [ ] 固定 `gridRateHz=200`、网格偏移 `[-15,-10,-5,0,5,10,15,20,25]ms`。
- [ ] 按 `sensorTimestampElapsedRealtimeNanos` 查找每个网格点的左右真实 IMU 帧，对 canonical 连续通道线性插值；精确命中时直接使用原值。
- [ ] 端点没有右支撑时等待第一个硬件时间超过 `+25ms` 的真实帧；禁止零填充、外推和静默跳过。
- [ ] 对窗口内真实采样间隔计算 `median_dt` 和 `max_gap=max(2*5ms, 4*median_dt)`；超过阈值则拒绝该样本并记录原因。
- [ ] 每个网格点用覆盖它的真实 IMU 接收时间执行触摸 ZOH：只选 `touchReceived <= imuReceived` 的最后触摸帧。
- [ ] 时间戳只用于对齐、插值和质量检查，不能进入模型特征名称。
- [ ] 输出固定形状 `[9, 11]` 或 `[9, 20]`，并同时返回网格质量元数据。
